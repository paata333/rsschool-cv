Codewars — Sum of Numbers

A JavaScript function that calculates the sum of all numbers in an array, including negative numbers. If the array is empty, it returns 0. 

function sum(numbers) {
  let total = 0;

  for (let i = 0; i < numbers.length; i++) {
    total += numbers[i];
  }

  return total;
}

console.log(sum([1, 5.2, 4, 0, -1]));
// Output: 9.2
